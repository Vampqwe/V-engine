# ⚙️ V-ENGINE — Микроядерный движок как операционная система для сайтов

> **Статус:** Архитектурный чертёж + Конституционный Суд. Реализация ядра не начата.  
> **Версия:** 0.2.0-alpha (Lex работает, ядро в проекте)  
> **Дата:** 31 октября 2026  
> **Философия:** Ядро — ОС. Сайт — приложение. Админка — бог. Doctor — честность. Lex — закон.

---

## 📐 ЧТО ЭТО ТАКОЕ

Это **не CMS**, **не фреймворк**, **не продукт**.  
Это **операционная система для веб-приложений**, где:

- Ядро знает только про инфраструктуру (БД, файлы, сессии, безопасность)
- Пользователь пишет бизнес-логику через контракты
- Админка живёт отдельной жизнью
- Doctor говорит правду о среде
- **Lex следит за соблюдением Конституции**
- Пустая БД — это warning, а не fatal
- Нулевые сторонние зависимости (только встроенные возможности PHP)

## 🧪 ТЕОРЕМЫ АРХИТЕКТУРЫ

> **Теорема 1 (Двух контуров):**  
> Зелёный lint ⇒ структура корректна; зелёный doctor ⇒ среда корректна.

> **Теорема 2 (Изоляции):**  
> Пользовательский код не может сломать ядро.

> **Теорема 3 (Авто-безопасности):**  
> Безопасность работает по умолчанию, без участия пользователя.

> **Теорема 4 (Универсальности):**  
> Пустая БД не ломает сайт.

> **Теорема 5 (Инфраструктурной полноты):**  
> Пользователь не пишет инфраструктуру. Пользователь пишет бизнес-логику.

> **Теорема 6 (Модульной чистоты):**  
> Один модуль — одна ответственность. Никакого смешивания.

### 3. Настройка веб-сервера

DOCUMENT_ROOT должен указывать на папку `/public`.

Пример для Nginx:
```nginx
server {
    listen 80;
    server_name mysite.loc;
    root /path/to/V-engine/public;
    index index.php;
    
    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }
    
    location ~ \.php$ {
        fastcgi_pass 127.0.0.1:9000;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }
    
    # Запрет доступа к .env и storage
    location ~ /\.env {
        deny all;
    }
    
    location ~ /storage/ {
        deny all;
    }
}
```
